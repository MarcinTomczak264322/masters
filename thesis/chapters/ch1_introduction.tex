\chapter{Introduction}

Simultaneous Localisation and Mapping (SLAM) is one of the fundamental problems in
mobile robotics~\cite{leonard1991mobile}.
It combines two tasks:
localisation which estimates the robot's position and orientation, and
mapping which builds a spatial model of the surrounding environment.
In SLAM, neither is assumed to be known in advance, so
both must be estimated at the same time from noisy sensor data.
Without a map the robot cannot plan paths or recognise places it has visited
before and without knowing its own position it cannot build a correct map.
Since GPS is unavailable in most indoor environments, SLAM is essential for
any robot that must work autonomously indoors.

The difficulty of SLAM problem comes from mutual dependency of two subtasks.
A correct map can only be built if the robot knows its position, and position
can only be estimated if there is a map to match against.
Even with a good algorithm, small sensor errors add up over time.
The key correction mechanism is loop closure~\cite{cadena2016past}: when
the robot returns to a place it has already visited, it recognises the match
and uses it to correct the drift that has built up in its trajectory.
Without it, errors grow without bound and SLAM algorithms fail.

The problem was first formalised in 1986 by Smith, Self, and
Cheeseman~\cite{smith1990estimating} and independently by
Durrant-Whyte~\cite{durrantwhyte1988uncertain}, who described how to reason
probabilistically about robot pose and map uncertainty.
The term SLAM was coined at the International Symposium on Robotics
Research (ISRR) in 1995~\cite{durrant2006simultaneous}.
Early solutions used Extended Kalman Filters, Rao-Blackwellised Particle
Filters, and maximum likelihood estimation.
Research then focused on observability, convergence, and consistency, which
led to the first widely used open-source libraries~\cite{cadena2016past}.
Supported sensors have since expanded from 2D laser scanners to 3D LiDARs,
cameras, and tightly-coupled inertial systems. The current focus has
shifted to robust long-term operation.

SLAM has been evolving since its formulation four decades ago, driven largely by the
growing use of mobile robots in indoor environments such as homes or
warehouses, where GPS is not available. Today it is used across many
domains: robotic vacuum cleaners navigate home environments, autonomous
vehicles map urban roads, unmanned aerial vehicles use it for inspection
and surveillance, and underwater drones can monitor coral reefs or detect mines.

Despite four decades of progress, SLAM is not a fully solved
problem~\cite{cadena2016past}. It can work reliably for slow-moving robots in
static indoor environments, but can struggle in fast-moving or highly dynamic
outdoor scenarios. Many open-source implementations exist, each making different design choices
with different trade-offs.
Choosing the right algorithm for a given robot and environment is not obvious,
which motivates a direct, controlled comparison.

\section{Goal and Scope}

The goal of this thesis is to evaluate eleven SLAM algorithms under identical conditions on a
differential drive robotic platform equipped with a 3D LiDAR, a stereo camera, and an IMU.
The algorithms cover the main families: sensor fusion, LiDAR odometry, 2D
and 3D LiDAR SLAM, tightly-coupled LiDAR-IMU SLAM, and visual SLAM.

All algorithms are tested on a single dataset recorded in NVIDIA Isaac Sim,
which provides exact ground-truth poses.
All experiments run under ROS\,2 (Robot Operating System).

Trajectory accuracy is measured using Absolute Trajectory Error (ATE) and
Relative Pose Error (RPE) against the simulator ground truth.
Map quality is assessed with Chamfer distance and F-score for algorithms that
produce a 3D point cloud, and visually for those that produce an occupancy
grid.
Computational cost is measured as mean CPU load and peak RAM usage during
execution.
